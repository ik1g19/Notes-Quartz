# IP Addressing

## IPv4

- 32 bit addressing
- 4 billion addresses

## IPv6

- 128 bit addressing
- Virtually unlimited addressing

## Important DIfferences


| Feature     | IPv4                               | IPv6                                |
| ----------- | ---------------------------------- | ----------------------------------- |
| Security    | Relies on additional protocols     | Built in security (IPSec)           |
| Performance | Limited due to NAT & fragmentation | More efficient routing and handling |
| Adoption    | Still widely used                  | Slowly being adopted                |
